1. Latent Space & Diffusion Basics

Core Pipeline: VAE Encode (RGB Image → Latent) → CLIP Encode (Text Prompt → Conditioning) → KSampler (Denoises Latent Noise guided by Conditioning) → VAE Decode (Latent → RGB Image)

Latent Space & VAE

  • Latent Space — A compressed mathematical tensor representation of an image, typically 48x smaller than pixel space.
  • VAE Encoder — Compresses pixel space (e.g. 512x512x3) into latent space (64x64x4) to save VRAM and execution time.
  • VAE Decoder — Decodes latent tensors back to visual RGB pixel spaces.
  • VAE Mismatch — Blur/static/color drift happens if VAE file does not match checkpoint architecture (SD1.5 vs SDXL).

CLIP & KSampler

  • CLIP Text Encoder — Translates prompt tokens into vectors used as steering guides (Conditioning).
  • Conditioning — Tells KSampler what content, lighting, or styles to pull out of the random noise.
  • KSampler — Chips away random noise over multiple steps (Euler, Karras) using UNet/Transformer models.
  • Denoise Value — At 1.0, replaces input with pure noise. At <1.0, performs img2img, preserving parts of the input shape.

2. Headless API & Automation

Headless Lifecycle: Open WebSocket /ws (Progress/Listen) → HTTP POST /prompt (Submit API JSON) → Monitor execution → HTTP GET /history (Get filenames) → Fetch Assets

ComfyUI API Architecture

  • Dev Mode Options — Enable in gear menu to unlock "Save (API Format)" button.
  • API JSON — Strips visual layout coordinates. Contains only node class names, inputs, and linkage maps.
  • Headless Server — Bypasses Web UI entirely, running ComfyUI as a command-line script on background GPU cluster servers.
  • Python urllib Dispatch — Posts the JSON workflow payload to http://[ip]:8188/prompt to queue runs.

Version Control Hooks (EA Pipeline)

  • Artist Commit — Artist submits base mesh/texture draft to Git or Perforce.
  • CI Trigger — Server post-commit hook triggers background Python script.
  • Headless Run — Script edits API JSON inputs, runs it on headless GPU, and fetches styled preview.
  • Auto-Submit — finalized styled card/avatar assets are committed back to the depot automatically.

3. Multi-Modality & Asset Pipelines

Consistency Strategy: 3D Engine Depth/Pose Pass → ControlNet Auxiliary Conditioning → IP-Adapter Style Lock → Single Grid Generation (Spritesheets)

ControlNet Preprocessors

  • Depth Maps — Extracted from engine camera, forces AI to preserve exact 3D geometry structure.
  • OpenPose — Extracted from skeletal rigs/mocap files, forces character pose consistency.
  • Canny / Lineart — Detects hard outlines, forcing the AI to preserve fine details, wireframes, or decals.

Spritesheets & Video Loops

  • Temporal Consistency — Naive frame-by-frame generation causes flickering. Prevent this by rendering all frames as a single wide grid.
  • IP-Adapter — Feeds reference image style vectors into the UNet, locking down the output identity.
  • AnimateDiff / SVD — Generates video frames by wrapping noise coordinates, creating seamless loops.
  • Lip Sync / Avatar — Combined audio generation and face mapping (SadTalker) to animate player portraits on the fly.

Headless client loop: "Establish WebSocket connection, POST prompt workflow JSON to /prompt, poll WebSocket for completion events, and fetch output via HTTP GET."
✓

✓
Spritesheet temporal lock: "Generate frames on a single grid sheet. Feed in an engine depth pass and use IP-Adapter to inject reference character style vectors."
✓
