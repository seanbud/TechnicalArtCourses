Course Cheat Sheet

Python runtime, data model, automation, and concurrency reference for C# / Java technical artists

Core rule: choose the data contract first, keep resource lifetimes explicit, make process boundaries observable, and distinguish waiting concurrency from CPU parallelism.

Model: source module → implementation compiler → bytecode/runtime → operating-system process.

Vocabulary

Lesson 2 — Names, Objects, Values, and Types

Model: names bind to objects; assignment rebinds a name, while mutation changes the object.

Surprises

  • Two names can reference one mutable object.
  • is tests identity; == tests value equality.
  • Use value is None for absence.
  • Empty built-ins, zero, False, and None are falsey.
  • Type hints document intent; ordinary Python does not enforce them automatically.

Class essentials

class Asset:
    category = "unknown"
    def __init__(self, path):
        self.path = path
        self.tags = []
    def add_tag(self, tag):
        self.tags.append(tag)

asset = Asset("tree.fbx")

Lesson 3 — Collections and Transformations

Choose by guarantee: list = ordered work; tuple = fixed grouping; dict = key lookup; set = unique membership.

Syntax

items = ["a", "b"]
point = (0, 1, 2)
meta = {"lod": 2}
unique = {"fbx", "gltf"}
empty_set = set()

first, *middle, last = items
tail = items[-2:]
subset = [x for x in items if rule(x)]

LINQ bridge

  • Comprehension ≈ readable result-building loop.
  • map(fn, xs) ≈ Select; lazy iterator.
  • filter(pred, xs) ≈ Where; lazy iterator.
  • sorted(xs, key=fn) ≈ OrderBy; new list.
  • Slicing selects positions; filtering tests content.

Lesson 4 — Functions and Reusable Behavior

Functions are values: pass callbacks, capture configuration in closures, manage resources with with, and wrap cross-cutting behavior with decorators.

Call shape

def export(path, output="build", *, dry_run=False):
    ...

def log(label, *steps, **metadata):
    ...

Patterns

  • Callback: function passed to another function.
  • Closure: nested function remembers enclosing values.
  • Bound method: instance access supplies self.
  • Context manager: with enters and cleans up.
  • Decorator: function returns a wrapper; use functools.wraps.

Lesson 5 — Classes and Contracts

Design default: pass collaborators into a composed pipeline; inherit for a genuine substitutable family; use multiple inheritance only for deliberate mixins.

Contracts

  • ABC: nominal contract; abstract methods block incomplete instantiation.
  • Protocol: structural shape for static checking.
  • Duck typing: call required behavior; validate boundaries.
  • super(): follows the MRO.

Composition

class Pipeline:
    def __init__(self, validator, converter):
        self.validator = validator
        self.converter = converter
    def run(self, record):
        errors = self.validator.validate(record)
        if errors:
            return {"ok": False, "errors": errors}
        return self.converter.convert(record)

Lesson 6 — Files, Streams, and Lazy Work

Separate: Path is a location, a file object is live access, and its cursor is the current position.

File mechanics

from pathlib import Path

path = Path("assets") / "manifest.json"
with path.open(encoding="utf-8") as stream:
    first = stream.readline()
    position = stream.tell()
    stream.seek(0)
    text = stream.read()

with path.open("rb") as binary:
    header = binary.read(16)

Lazy mechanics

def records(path):
    with path.open(encoding="utf-8") as stream:
        for line in stream:
            if line.strip():
                yield line.strip()

match = next((x for x in records(path)
              if "ERROR" in x), None)

Lesson 7 — Reliable Tools and Automation

Boundary rule: exceptions describe in-process failure; stdout/stderr/exit codes describe process behavior.

Exceptions

try:
    value = int(record["width"])
except (KeyError, ValueError) as error:
    raise ConversionError("bad width") from error
else:
    use(value)
finally:
    release_or_log()

Subprocess

completed = subprocess.run(
    ["converter", "--input", source],
    capture_output=True, text=True, timeout=60
)
if completed.returncode != 0:
    raise RuntimeError(completed.stderr)
  • Catch narrowly; preserve causes with raise ... from.
  • Prefer argparse to manual sys.argv for real CLIs.
  • Use argument lists; avoid shell=True unless deliberately required.
  • subprocess.run waits by default; descendant cleanup is platform/tool dependent.
  • Deliverables include interpreter, dependencies, executables, paths, permissions, and configuration.

Lesson 8 — Async, Threads, Processes, and Deployment

Decision rule: async for cooperative I/O concurrency; threads for appropriate shared-process work; processes for isolation or CPU scaling when IPC cost is acceptable.

Async sequence

async def fetch(name):
    await io_operation(name)
    return name

async def main():
    coroutine = fetch("tree")
    result = await coroutine
    task = asyncio.create_task(fetch("hero"))
    results = await asyncio.gather(task)
    return result, results

Concurrency map

  • Event loop: one coordinator interleaves tasks at await.
  • Thread: shares process memory; protect multi-step state.
  • Queue: explicit worker messages often beat shared mutation.
  • Process: private memory; use IPC.
  • CPU caveat: standard CPython builds have a GIL; async does not parallelize Python CPU loops.

Interview Prompts

Explain clearly

  • Why is a path not a file pointer?
  • When does a coroutine body run?
  • Why does a set help membership but not ordered output?
  • What does super() follow?

Design under pressure

  • Separate parsing, validation, conversion, and delivery.
  • Prefer composition for replaceable pipeline stages.
  • Keep process boundaries observable and serializable.
  • State behavior on failure, timeout, cancellation, and shutdown.
