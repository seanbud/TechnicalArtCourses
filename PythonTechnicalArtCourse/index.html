Python for Technical Artists

A concise bridge from C# / Java thinking to Python project fluency

This eight-lesson course adapts Alex's broad 50-assignment Python curriculum for experienced technical artists. It emphasizes Python's runtime, object model, idioms, automation boundaries, and concurrency mental models before later testing and technical-art applications.

Foundations

How Python executes, names objects, and transforms everyday data.

01

How Python Runs and How Projects Start

Interpreter, bytecode, environments, imports, entry points, and process output
02

Names, Objects, Values, and Types

Binding, mutability, truthiness, type hints, and first classes
03

Collections and Pythonic Data Transformations

Core collections, slicing, unpacking, comprehensions, and LINQ comparisons
04

Functions, Calls, and Reusable Behavior

Arguments, callbacks, closures, binding, context managers, and decorators

Design and Systems

Python's contracts, data flow, automation boundaries, and concurrency choices.

05

Classes, Contracts, and Composition-First Design

Inheritance, protocols, duck typing, mixins, multiple inheritance, and MRO
06

Files, Paths, Streams, and Lazy Work

Pathlib, file objects, buffering, iterators, generators, JSON, and CSV
07

Reliable Tools and Automation

Tracebacks, custom errors, CLI contracts, subprocesses, and deliverables
08

Async, Threads, Processes, and Deployment Mental Models

Event loops, tasks, worker models, process isolation, IPC, servers, and packaging
